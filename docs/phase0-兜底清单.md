# Phase 0 · 系统级兜底清单（自建系统的最后防线）

> 自建系统只能覆盖"手机有电、有网、未被刷机"的场景。
> 以下两条**厂商级通道**是手机被锁屏关流量、被换 SIM、被擦除前的官方高精手段，必须提前开启并验证。
> ⚠ 关键原则：**丢手机当天才去开，就来不及了。**

## 1. 小米查找设备（国内行货首选，走小米云 + SIM 独立通道）

### 开启（现在就做）
- [ ] 设置 → 小米账号 → 云服务 → **查找设备 → 开启**
- [ ] 同页打开 **"离线查找"**（借助其他小米设备蓝牙众包网络定位）
- [ ] 设置 → 密码与安全 → 确认已设置**锁屏密码**（无锁屏密码=丢失后门户大开）
- [ ] 设置 → 密码与安全 → 系统 → **关机需密码/验证**（若有此选项；防止捡到者直接关机断联）

### 验证（必须做一次）
- [ ] 任意电脑浏览器登录 **i.mi.com** → 查找设备 → 能看到本机当前定位
- [ ] 试一次"响铃"功能（手机会最大音量响，即使静音状态）
- [ ] 记住：此功能走的是手机流量+短信通道，WiFi 被关也能用

## 2. Google 查找设备（若已安装 Google 服务框架）

- [ ] google.com/android/find → 登录手机上的 Google 账号 → 确认本机可见
- [ ] 设置 → Google → 安全 → 查找我的设备 → 开启
- [ ] 国内行货若未预装 GMS 则跳过本节，以小米通道为准

## 3. SIM 与身份信息（报警/补卡要用）

- [ ] 设置 **SIM 卡 PIN 码**（防止 SIM 被插到别的手机收验证码）
  - 设置 → 密码与安全 → 系统安全 → SIM 卡锁定
  - ⚠ PIN 码记入密码管理器，连错 3 次会锁卡需 PUK
- [ ] 拨 `*#06#` 记录 **IMEI**（15 位），存到云笔记/家人手机
- [ ] 记录运营商客服号：移动 10086 / 联通 10010 / 电信 10000（挂失补卡用）

## 4. 三层防御体系全景

| 层级 | 手段 | 覆盖场景 | 失效场景 |
|---|---|---|---|
| L1 自建系统 | PhoneLocation App + 本项目 | 窗口内有电有网，分钟级轨迹，**含历史轨迹** | 被刷机/关机/断网/窗口外休眠 |
| L2 小米云 | i.mi.com 查找设备 | 关流量走短信，可响铃/锁定/擦除 | 被刷机且退出账号 |
| L3 线下 | IMEI + 运营商 + 报警 | 最终法律途径 | — |

**每季度演练一次**：模拟丢失（关 WiFi 走流量）→ 开 /map 看位置 → 登 i.mi.com 响铃 → 记录各环节耗时。
